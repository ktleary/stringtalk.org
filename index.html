Stringtalk

Stringtalk is based on an idea that simple tools, like two cans and a string, can provide meaningful information.

All tools are free, GPL open-sourced with no advertisements or tracking. Information wants to be free.

Resources

invidi.link
A simple tool to convert URLs to available invidio.us instance links
Twit2Nit
View Twitter on Nitter by supplying a twitter username or url.
Searx Random Instance
Redirect to a random searx instance reporting healthy monitor stats..
Links
A place to read and share content from around the web. Links is a standalone lemmy instance (see join.lemmy.ml).
Hegel
Perform the Hegelian Dialectic on any idea.
Summer of Letters
Add up the values of letters in a list of words.
Fibonacci Times
Add or subtract Fibonacci cyles to a given date..
Genstar
An interactive writing prompt.
